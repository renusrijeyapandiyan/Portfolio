The problem

Sellers on online marketplaces get flooded with buyer negotiation messages, and manually checking each one against pricing rules is slow and inconsistent. MarketReply AI automates that first pass.

Key features

▸Gemini 2.5 Flash reads buyer intent (discount, delivery, info)
▸Seller rules enforced automatically on every reply
▸Ready-to-send drafted replies in seconds
▸JWT-secured, multi-seller account isolation
▸Analytics dashboard: intent distribution + rule compliance rate
▸Live, browsable directory of registered sellers

My role

Built end-to-end: the React/Vite front-end, the Spring Boot REST API, the MongoDB Atlas data layer, and the Gemini prompt design that turns a seller's raw pricing rules into a structured system prompt the model can reliably follow. I also implemented JWT auth from scratch and deployed both services to Render.

Challenges & what I learned

Getting Gemini to consistently respect hard constraints (minimum price, accepted payment methods) rather than just "being polite about them" took several rounds of prompt iteration. I learned to separate the rules into an explicit structured block in the prompt rather than prose, which made compliance far more reliable — a pattern I now reach for whenever an LLM output needs to satisfy business constraints.
